# 提交审阅

在 Pi TUI 中浏览当前暂存区，再确认提交范围和完整提交信息。扩展只读，不执行 `git add`、`git commit` 或任何远程操作。

## 使用

运行 `/reload` 后，`git-commit-cn` 可以调用 `commit_review({ message: "fix: 修复令牌刷新" })`。用户也可手动打开：

```text
/commit-review fix: 修复令牌刷新
```

手动命令只显示审阅结果通知，不触发 Agent 提交。工具返回 `confirmed`、`adjust` 或 `cancelled`；只有 `confirmed` 是所展示暂存快照和完整信息的本地提交授权。工具失败、非 TUI、取消或关闭均不算同意。调用前仍须检查敏感内容、文件追踪必要性及范围授权。

## 界面

- lazygit 风格分栏，仅包含本次提交的暂存文件、unified diff 和提交信息，不启动 lazygit，也不提供暂存、切换分支等 Git 操作。
- 宽度 ≥90 列：左侧按目录层级显示文件树，右侧 diff，当前区域使用高亮边框；窄终端：单栏切换。目录与文件名分别显示，长名称自动换行；`↑↓` 只选择文件，不会停在目录标题上。
- diff 顶部显示所选文件路径并自动换行；`p` 打开完整路径页，包含重命名前后路径，`↑↓`、`PgUp/PgDn` 滚动查看，`p` 或 `Esc` 返回。
- 顶部始终显示提交分支（去掉 `refs/heads/` 前缀），分离 HEAD 时明确显示状态与提交 SHA；第二行显示仓库、文件数量与增删统计。
- 终端空间足够时，下方独立面板预览前三行提交信息，`m` 展开完整内容；较矮终端使用 `m` 查看。新增、删除、重命名和二进制文件使用 Git 的实际差异表示。
- `Tab` 切换文件列表/差异；文件列表中按 `Enter` 查看差异，差异中再次按 `Enter` 将焦点返回文件列表，不退出审阅；`↑↓`、`PgUp/PgDn` 浏览。
- `/` 筛选文件路径，输入后 `Enter` 返回浏览；筛选中 `Esc` 清空筛选。
- 差异中 `←→` 横向滚动，`Home/End` 到顶部/底部，`[` / `]` 跳转改动块，`w` 切换折行。
- 底部“操作”区域按行列出当前页面的快捷键，窄屏自动换行；优先保留操作区，空间不足时缩小内容区。
- `m` 查看完整提交信息；`c` 直接确认当前暂存快照和提交信息，校验通过后结束审阅，无需再按 `Enter`。`a` 请求调整范围或信息。
- 宽屏与窄屏行为一致：差异中按 `Esc` 返回文件列表，文件列表中再次按 `Esc` 才取消审阅；路径页、信息页按 `Esc` 返回上一层。校验中 `Esc` 或任意阶段 `Ctrl+C` 取消。

逐文件按需加载；切换文件保留滚动位置，切换折行回到文件顶部。支持键盘操作，不依赖鼠标。

## 边界

- 仅审阅暂存区。需要暂存时，Skill 先另行确认范围和暂存操作。工作区的剩余修改只统计数量，不混入 diff。
- 快照校验包含仓库路径、分支、HEAD 和完整 index 条目。未完成的合并、cherry-pick、revert、rebase、冲突或空白错误会阻止确认。
- 每次加载差异前后、最终确认时及工具返回前重新检查快照；变化必须重新打开审阅。确认后到实际提交之间仍需由调用方复核；这不是 Git 锁，也不替代提交前测试或秘密扫描。
- 单次 Git 输出最多 16 MiB，超限报错，不静默截断；非 UTF-8 输出报错。文件中的终端控制字符和双向文本控制字符转义显示。文本按需缓存到本次审阅结束。
- RPC/print/JSON 不支持此 TUI；Skill 回退到可用的确认交互，不自动同意。

## 验证

本仓库的 Pi 托管安装下（Node.js 24）：

```sh
node --experimental-transform-types --test agent/extensions/commit-review/review.test.ts
```

测试使用临时 Git 仓库、真实 Pi UI 组件及模拟终端上下文，覆盖初始提交、目录树、同名文件、长文件名与路径换行、完整路径滚动、特殊路径、重命名、二进制、删除、未暂存修改、快照变化、未完成 Git 操作、非 UTF-8、输出上限、窄屏/缩放、滚动、筛选、确认及取消。不操作用户仓库的 index/HEAD；不等同于真实终端端到端验证。
